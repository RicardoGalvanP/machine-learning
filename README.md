# Machine Learning

Machine learning projects (supervised and unsupervised learning, recommender systems and, as the program advances, ensembles and neural networks) built in Python during my Master's in Applied Artificial Intelligence at Tecnológico de Monterrey. The focus is on honest evaluation: baselines, leakage-free pipelines, validation splits, cross-validation, error costs and responsible use of models. Each folder contains a README and English and Spanish notebooks.

## Projects

| Project | Focus | Techniques | Status |
|---|---|---|---|
| [employee-attrition-prediction](employee-attrition-prediction/) | Binary classification on imbalanced data | Logistic regression (ElasticNet), KNN, Pipelines, threshold tuning, sensitive-attribute audit | Predictive model |
| [movie-recommender-systems](movie-recommender-systems/) | Recommender systems on MovieLens 1M | Truncated SVD, ALS from scratch, hybrid content model, popularity baselines, LLM agent with code verification | Offline evaluation |

More projects will be added over time.

## Stack

Python, Pandas, NumPy, SciPy, Scikit-learn, Matplotlib, Seaborn, Gemini API, Google Colab
